Software factory

how these tools ship

Agentic development environments (ADEs) are the future of building software, and teams not using one are already behind. Here's mine: a coordinator picks up the next item on a roadmap I approved. One agent writes the change, a different one tries to break it, and nothing merges until it passes. Product and security decisions stay with me.

  • 1 in 3QA runs sent a change back before it could merge.
  • 3 modelsBuilders run on two Claude models, and every change is checked by a third model from a different vendor.
  • Self-gatedsast-triage scans every pull request to this website and both tools.

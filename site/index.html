PROJECT

sast-triage

Labels each Semgrep finding new or pre-existing, ranks it P1–P3, and fails the check only on new P1s.

Stack: Python · Semgrep · GitHub Actions · FastAPI · GitHub API · pytest

On OWASP NodeGoat, a full scan finds 7 new P1 findings. With --base HEAD~2, its last two pull requests pass with no new findings.
